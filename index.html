  • Profiled a GPT-2 decoder transformer (6 layers, d_model=512, 8 heads, vocab=50,257) on a Tesla T4 using torch.profiler and Nsight Systems; analyzed per-kernel timing via Kineto traces in Perfetto to quantify the GPU time breakdown.
  • Quantified that matmul (cuBLAS sgemm) consumes 53.50% of GPU time while memory-efficient attention (CUTLASS FMHA) consumes only 6.77% at seq_len=128 — contradicting the common "attention is the bottleneck" framing for short contexts.
  • Measured backward pass at 1.99× forward (avg over 3 steps), traced to two sgemm launches per linear layer in backward (grad-activations + grad-weights).
  • Identified the Adam optimizer consuming 20.12% of GPU time via multi_tensor_apply kernels — the standard motivation for fused/foreach optimizers on small models.
  • Benchmarked mixed precision (AMP) training: FP16 vs FP32 throughput, memory footprint, and kernel-level differences, including GradScaler overhead.
  • Built a tiered, reproducible lab repo (toy ops → mixed precision AMP → transformer profiling) with raw traces, Colab notebooks, and documentation backing every claim with trace data.
